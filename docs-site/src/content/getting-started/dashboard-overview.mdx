# Dashboard Overview

The dashboard is your financial command center. It shows a real-time snapshot of your STR portfolio.

## Stat Cards

The top of the dashboard shows 6 key metrics:

| Card | What It Shows |
|------|--------------|
| **Monthly Revenue** | Total revenue received this month across all properties |
| **Monthly Spend** | Total expenses this month across all properties |
| **Net Profit** | Revenue minus expenses (green when positive, red when negative) |
| **Properties** | Number of active properties |
| **Pending** | Bills in your inbox waiting for review |
| **Anomalies** | Unusual spending patterns detected |

## Recent Expenses

Below the stat cards, you'll see your most recent expenses. Click any row to edit it.

## Navigation

Use the sidebar to access all sections:

- **Dashboard** — Overview and stats
- **Expenses** — Full expense list with search, sort, and filter
- **Revenue** — Revenue tracking and management
- **Properties** — Add and manage your properties
- **Inbox** — Review bills parsed from email
- **Analytics** — Charts and spending trends
- **Tax** — Schedule E tax preparation
- **Integrations** — Connect your PMS, bank, and tools
- **Alerts** — Anomaly alerts and notifications
- **Settings** — Profile and preferences
- **Billing** — Manage your subscription

## Empty State

If you're new and haven't added any data yet, the dashboard shows a preview of what it looks like with data and guides you through getting started.
