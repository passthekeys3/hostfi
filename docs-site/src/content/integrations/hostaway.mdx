# Hostaway

Connect your Hostaway account to sync properties, reservations, and revenue.

## Connecting

1. Go to **Integrations** and find Hostaway
2. Click **Connect**
3. Enter your Hostaway API credentials (API Key and Account ID)
4. Click **Save**
5. Select which properties to sync

## Finding Your API Credentials

In Hostaway, go to **Settings > API > API Keys** to find or create your API key and account ID.

## What Syncs

- **Properties** — All listings from your Hostaway account
- **Reservations** — Booking details with financial data
- **Revenue** — Booking amounts, fees, and payouts

## Sync Schedule

HostFi syncs with Hostaway daily via an automated cron job. You can also trigger a manual sync at any time.

## Disconnecting

Click **Disconnect** on the Hostaway card. Previously synced data is preserved.
