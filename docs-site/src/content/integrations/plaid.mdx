# Plaid (Bank Sync)

Connect your bank accounts to automatically import transactions and match them to properties.

> **Coming soon** — Plaid integration is built and awaiting production access approval. This page describes the functionality that will be available at launch.

## How It Will Work

1. Go to **Integrations** and find Plaid
2. Click **Connect**
3. Search for your bank and sign in securely through Plaid
4. Select which accounts to connect
5. Map each bank account to a property

## What Syncs

- Bank transactions are imported automatically
- Transactions are matched to the appropriate property based on your account mapping
- HostFi suggests categories based on the transaction description

## Property-to-Account Mapping

During setup, you'll assign each bank account to a property. This is how HostFi knows which transactions belong to which property. If you use one account for multiple properties, you can manually assign transactions after import.

## Security

Plaid is a trusted financial data provider used by thousands of apps. HostFi never sees or stores your bank credentials. All communication happens through Plaid's encrypted infrastructure. Access tokens are encrypted with AES-256-GCM.
