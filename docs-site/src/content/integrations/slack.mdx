# Slack

Get HostFi notifications in Slack, parse receipts via file uploads, and query your data with slash commands.

> **Business feature** — Slack integration requires a Business plan.

## Connecting

1. Go to **Integrations** and find Slack
2. Click **Connect**
3. Authorize HostFi in your Slack workspace
4. Select which channel to receive notifications in

## Notifications

HostFi sends notifications to your connected Slack channel for:

- New bills parsed from email
- Anomalies detected
- Overdue expenses

## Receipt Parsing

Upload a receipt image directly in the connected Slack channel. HostFi will parse it and create an expense, just like the in-app receipt scanner.

## Slash Command

Type `/hostfi` in any channel to interact with HostFi:

- `/hostfi spending` — Quick spending summary
- `/hostfi status` — Account and sync status

## Disconnecting

Click **Disconnect** on the Slack card. Notifications will stop but all data is preserved.
