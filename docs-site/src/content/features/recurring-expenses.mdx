# Recurring Expenses

Set up recurring expenses and HostFi automatically creates them each month.

## Setting Up a Recurring Expense

1. When adding or editing an expense, toggle **Recurring** on
2. The expense will be automatically re-created on the same date each month

## Auto-Suggest

When you select certain categories, the recurring toggle automatically turns on:

- Rent
- Insurance
- Utilities
- Mortgage
- Subscription
- Management
- Cleaning

You can always turn the toggle off if the expense is a one-time charge.

## Managing Recurring Expenses

Recurring expenses are regular expenses with a recurring flag. You can:

- Edit any instance without affecting future occurrences
- Turn off recurring on any expense to stop future auto-creation
- Delete an instance without stopping the recurring cycle

## How Auto-Creation Works

HostFi runs a daily check for recurring expenses that are due. When one is due, a new expense is created with the same details (property, category, amount, description) and the current month's date.
